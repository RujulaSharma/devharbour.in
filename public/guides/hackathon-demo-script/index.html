A three-minute hackathon demo script

Use a timed script to present the problem, show your prototype, and finish with evidence.

Pick one workflow that proves your idea. If your prototype helps students report lost property, show someone adding an item and another person finding it. Prepare a small set of realistic dummy records so both actions are easy to see.

0:00–0:35 · Give the audience the problem

“Students report lost items in scattered group chats. A week later, nobody can find the original post. Our prototype lets a student publish a listing and lets another student filter by location.”

0:35–2:15 · Demonstrate one complete task

Show the listing form, save a dummy item, then find it from a separate browser tab. Zoom in so the result is readable. Explain the decisions a reviewer can see, such as why the location is a filter. Rehearse from a fresh session and have a recording of the same workflow ready if the demo fails.

2:15–3:00 · State what you measured and what comes next

Say what you tested and who tested it. If all you have is a timed walkthrough with three teammates, describe that directly. Name one limitation and a next test. Put your demo link and setup instructions in the submission so judges can try it after the pitch.

Run this script once with a stopwatch, cut one screen if you run over, then use the submission checklist before you upload.

## Additional findings

- A voter could become the owner of a copied gallery project and receive submission credit. Gallery votes now use dedicated rows, and private projects are excluded from public voting. [server/db-postgres.js line 487](../server/db-postgres.js#L487)
- Revoked legacy credentials were still reported as verified. Both verification entry points now read the stored status. [api/certificates/verify/[id].js line 45](../api/certificates/verify/[id].js#L45)
- Google account linking accepted email claims without establishing that Google controlled the address. Linked Google accounts now check the stored subject. New links require a Gmail or Google Workspace identity and an existing password signup must already be verified. Successful email verification also revokes earlier sessions. [server/routes/auth.js line 224](../server/routes/auth.js#L224) · [server/db-postgres.js line 1121](../server/db-postgres.js#L1121)
- A production database failure could redirect account operations to local SQLite. The configured production adapter now fails closed. A separate operator setup script disabled TLS certificate checks and now validates the database certificate. [server/db.js line 1794](../server/db.js#L1794) · [scripts/setup_supabase_db.js line 18](../scripts/setup_supabase_db.js#L18)
- Two older tracked standalone builds still contained browser-only login code. The standalone build now regenerates all three distribution copies from the canonical page. [scripts/build_standalone.js line 21](../scripts/build_standalone.js#L21)
- Two product rules remain open to abuse. A verified user can earn submission XP by creating distinct low-quality projects, and can mark lessons complete without evidence of reading. Product owners should decide what constitutes an accepted project or completed lesson before tying prizes to these scores. [server/db-postgres.js line 554](../server/db-postgres.js#L554) · [server/routes/courses.js line 62](../server/routes/courses.js#L62)
- Registration explicitly reports an existing email address. This permits account discovery even with throttling. A privacy-preserving registration response would require an accompanying email-based account recovery experience. [server/routes/auth.js line 34](../server/routes/auth.js#L34)

## Release and historical exposure

Apply the certificate migration and then the access-control migration before deploying. The runtime database role must be able to update the new counters. Exercise Google signup with an authorized staging Gmail account, check the verification link from a signed-out browser, and open the PDF on Android. [README.md line 135](../README.md#L135)

The formerly public helper was untracked. If it was served or deployed, revoke the session it contained and check access logs. Revoke old demo sessions on installations that imported SQLite users into PostgreSQL. Earlier Git commits, cached downloads, and existing clones can still contain participant data. Repository history cleanup and production changes were outside these local commits.
